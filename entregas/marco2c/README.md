# Relatório do Marco 2c

[**Baixar relatório e dados em ZIP**](Marco2c-relatorio-e-dados.zip?raw=true)

[**Ler o relatório completo**](MARCO2C-REPORT.md)

1.050 avaliações concluídas, sem erros de auditoria. A comparação reservada com 100 fundadores usa 25 seeds pareadas; os demais grupos usam 100 seeds por regra. Os arquivos JSON contêm resultados e medições; não é necessário instalar Node.js para ler o relatório.

Para baixar pelo GitHub, abra o ZIP e clique em **Download raw file** (ícone de seta para baixo). No Windows, clique com o botão direito no arquivo baixado e escolha **Extrair tudo**.
