Perdão é uma renúncia unilateral, mesmo que o outro aceitasse conversar. Uma resposta negativa não fecha o objetivo automaticamente; as ações são reavaliadas.

Rotinas consecutivas do mesmo agente/ação viram um episódio antes de calcular profundidade. Eventos significativos interrompem o agrupamento.
